# Security

Report a security problem in this pack privately, through
[GitHub's private vulnerability reporting](https://github.com/maester365/maester-pack-scubagoggles/security/advisories/new),
not in a public issue. The same link is the pack's `SecurityContact` in `maester-pack.json`.

A problem in ScubaGoggles goes to [cisagov/ScubaGoggles](https://github.com/cisagov/ScubaGoggles/security), and one
in Maester itself to [maester365/maester](https://github.com/maester365/maester/security).
